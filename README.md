
# Podjela rada po članovima tima

U nastavku je prikaz kako je projekt podijeljen po semantičkim domenama. Svaki član je preuzeo svoj dio modela i pripadajuću SQL datoteku s pogledima i upitima.

| Član | Ime | Semantička domena | Tablice | SQL datoteka |
|------|-----|-------------------|---------|--------------|
| **Član 1** | **Tomislav** | Geografija i osobe | `drzava`, `grad`, `adresa`, `osoba` | `upiti_clan1.sql` |
| **Član 2** | **Dario** | Zaposlenici i HR | `zaposlenik`, `pozicija`, `pozicija_zaposlenika`, `radna_smjena` | `upiti_clan2.sql` |
| **Član 3** | **Vedran** | Brodovi i pristaništa | `tip_broda`, `brod`, `pristaniste`, `dokovanje` | `upiti_clan3.sql` |
| **Član 4** | **Matej** | Teret i skladišta | `teret`, `manifest`, `skladiste`, `skladistenje_tereta` | `upiti_clan4.sql` |
| **Član 5** | **Jakov** | Inspekcije, certifikati i financije | `inspekcija`, `certifikat`, `usluga`, `placanja`, `recenzija_broda` | `upiti_clan5.sql` |
